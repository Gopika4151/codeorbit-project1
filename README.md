# 🤖 Rule-Based AI Chatbot

## 📌 Project Overview
The Rule-Based AI Chatbot is a simple interactive chatbot developed using HTML, CSS, and JavaScript. It responds to user messages using predefined keywords and responses.

This project was developed as part of the CodeOrbit Tech Artificial Intelligence Internship.

## 🎯 Objective
To develop a simple chatbot that understands basic user inputs and provides appropriate responses using predefined rules.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code

## ✨ Features
- Interactive chatbot interface
- Greeting message detection
- Answers common questions
- Keyword-based response generation
- Unknown input handling
- Enter key support
- Responsive web design

## 📂 Project Structure
```text
CodeOrbit_RuleBasedChatbot/
│

```

## ⚙️ How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Type a message in the chatbot.
5. Receive an automatic response.

## 🧠 Working Principle
1. The user enters a message.
2. JavaScript receives the input.
3. The input is converted into lowercase.
4. The chatbot checks predefined keywords.
5. A matching response is displayed.
6. If no keyword matches, a fallback response is displayed.
